# Data

The input and intermediate data files required to reproduce the scGRAIN analyses are publicly available on Zenodo:

**https://doi.org/10.5281/zenodo.24334859**

Download `scGRAIN_data_v1.0.zip` and extract it into the root directory of the cloned repository.

The expected directory structure is:

```text
scGRAIN/
└── data/
    ├── output_top50_bg_centered_Parenchyma_cell/
    ├── tf_program_ces_top50_bg_centered_cov_fix13/
    ├── TF_program_result50/
    ├── RNA/
    ├── atacRNA/
    ├── cell_metadata.csv
    ├── RNA_scRNA_Parenchyma_cell.spectra.k_100.dt_0_5.consensus.txt
    ├── RNA_scRNA_Parenchyma_cell.usages.k_100.dt_0_5.consensus.txt
    └── trans.txt
```

See the Zenodo record for the complete data archive and file list.
